# Широкое время в турецком — Timur Turkish

Geniş zaman: правила и 13 исключений. Истории в духе коротких тредов: рубленые фразы, диалоги через тире, развязка отдельной строкой,
девять интерактивов, озвучка турецких форм. В конце — переход на платформу **Alterna Timur A0 → C1**.

Дизайн повторяет кейс Behance «Futuristic Habitat» (Orbix Studio): мятный фон, сжатые синие заголовки,
эко-город с ветряками, монорельсом и рекой, переход «набросок → ч/б → цвет», постеры на остановках,
ноутбук и телефон с записями экрана, разворот-книга с кольцами, финальный экран «Спасибо, что докрутил».

## Интерактивы

1. Город в трёх состояниях — тянешь границу: набросок, тени, цвет
2. Шесть карточек-переворотов: фразы, которые уже в широком времени
3. Город глаголов — дом растёт по слогам, вывеска с суффиксом падает на крышу
4. Навигатор — фишка идёт по трём вопросам; можно вписать свой глагол
5. Вывески — гармония гласных и t → d
6. 13 особняков — зажигаешь дома, счётчик 13/13, конфетти из листьев
7. Двойники — al/çal, gel/del…: найди исключение
8. Мехмет — караоке из 13 строк, по одному исключению в каждой
9. Конструктор — лицо, отрицание, вопрос; z выпадает у «я» и «мы»

## Сборка и озвучка

```bash
python3 tools/build.py
python3 tools/gen_audio.py
python3 tools/build.py
```

Второй `build.py` нужен, чтобы список готовых mp3 попал в страницу. Свою запись можно положить
в `assets/audio` с тем же именем — код сначала ищет файл и только потом включает синтез браузера.
